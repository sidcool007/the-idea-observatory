# The Idea Observatory

**Look Closer. Understand Deeper.**

An independent multidisciplinary digital publication exploring ideas, discoveries and stories that help readers understand the world.

## Project status

Foundation setup in progress. The public website is not yet deployed. Editorial content will be added only after research, fact-checking and explicit human approval.

## Editorial sections

- Science & Discovery
- Technology & AI
- History & Civilisations
- Mind & Philosophy
- Business & Money
- World & Culture
- Travel & Places
- Life & Living

## Technology

- Astro + TypeScript
- Markdown/MDX content
- Static-first architecture
- Cloudflare Pages deployment target
- GitHub as the source of truth

## Editorial safeguards

- Drafts are not published automatically.
- Every article requires explicit administrator approval.
- Research sources and factual claims must be reviewed before publication.
- No AI-generated content is published without human review.

## Local development

```bash
npm install
npm run dev
```
